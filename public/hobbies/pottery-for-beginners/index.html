Pottery for beginners

Learn the basics of trying pottery, including hand-building, studio classes and how to plan a first project.

Where to start

Hand-building is a beginner-friendly way to try clay. A studio class can provide materials, tools and firing, but prices and availability vary.

Try this simple plan

  1. Look for an introductory hand-building session
  2. Check whether clay and firing are included
  3. Start with a small pinch pot or dish
  4. Allow time for drying and firing if using a studio
