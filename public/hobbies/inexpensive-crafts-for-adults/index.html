Inexpensive crafts for adults

Explore affordable craft projects using basic or reused materials, and choose one to try this weekend.

Where to start

Budget-friendly crafts include paper collage, simple sketching, hand lettering and upcycling materials you already have.

Try this simple plan

  1. Check your home for reusable paper and containers
  2. Pick a small project that can be finished in one sitting
  3. Set a supplies budget before shopping
  4. Make a second version using what you learned
