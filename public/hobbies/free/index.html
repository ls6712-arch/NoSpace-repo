Free hobbies to try without spending money

Discover free or nearly free hobbies, from walking and drawing to journaling and learning new skills.

Where to start

Walking, library reading, sketching with supplies you already own and writing are often free ways to explore an interest. Some activities may still involve optional costs.

Try this simple plan

  1. Walk a new public route in daylight
  2. Borrow a book from a local library
  3. Write a page about something you noticed today
  4. Sketch an object using paper you already have
