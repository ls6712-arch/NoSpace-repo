Easy hobbies for beginners

Beginner-friendly hobbies that require little setup, with realistic first steps you can try this week.

Where to start

The easiest hobbies are accessible, low-pressure and simple to repeat. Try walking, phone photography, journaling or beginner drawing.

Try this simple plan

  1. Choose one activity you can start today
  2. Keep the first attempt to 15–30 minutes
  3. Use existing supplies instead of shopping first
  4. Schedule a second session only if you enjoyed it
